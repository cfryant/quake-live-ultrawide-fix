Quake Live Ultrawide Fix

True 21:9 and 32:9 (anything wider than 16:9) for Quake Live on Steam, with no horizontal stretching, applied to a separate offline copy of the game.

⚠️ VAC / anti-cheat warning: read this first

⛔ Do not use for online play! It WILL trigger Valve's Anti-Cheat rendering your copy permanently unplayable! For offline bots use ONLY!.

  • What it changes: the installer makes a separate copy of your Quake Live install and modifies one game file in that copy: cgamex86.dll inside baseq3\bin.pk3 (4 bytes). No memory patching, no DLL injection, no background process.
  • Your original Steam install is never modified.
  • Valve treats modified game files as cheating. Running the patched copy while Steam is online, or joining servers with it, could get you a VAC ban. A ban is permanent for Quake Live (and possibly other games on the same engine), but it does not delete your Steam account. Pure online servers should refuse the modified copy anyway.
  • Offline/local play only, with Steam in Offline Mode. Use at your own risk; no warranty.

The problem

Quake Live only widens its horizontal field of view up to 16:9. At wider resolutions it renders a 16:9 view and stretches it sideways. At 3440×1440 everything is about 1.34× too wide; at 32:9, 2×. r_mode -1 with r_customWidth/Height gives native resolution but the image is still stretched.

Why there's no cvar fix

  • The game logic fixes the vertical FOV from cg_fov on a 640×480 (4:3) basis, then derives the horizontal FOV from the integer preset r_aspectRatio: 0 = 4:3, 1 = 16:9, 2 = 16:10, anything else = 5:4.
  • The engine resets r_aspectRatio on every video restart (1 for anything 16:9 or wider), so console or config values don't last.
  • There's no r_customPixelAspect or similar cvar, and cg_fov changes zoom, not aspect ratio. Flawless Widescreen has no Quake Live plugin.

How the fix works

The 16:9 preset computes fov_x = 2·atan(tan(fov_y/2) · 16/9). The 9.0 is stored once in cgamex86.dll (offset 0x7246C). The installer replaces it with 16·Height/Width (3440×1440 → 6.6977, 5120×1440 → 4.5). The engine already picks that preset for ultrawide modes, so you get correct Hor+ with no cvar changes.

Requirements

Windows 10/11 with Windows PowerShell 5.1 (built in) or PowerShell 7+. No third-party tools. Quake Live from Steam (app 282440), about 1.1 GB free, and a resolution wider than 16:9.

Install

  1. Download the release zip from the repository's Releases page and extract it. Close Quake Live.
  2. Dry run (checks everything, writes nothing): 
    powershell -ExecutionPolicy Bypass -File .\Install-UltrawideFix.ps1 -Destination 'D:\Games\QuakeLive-Ultrawide' -WhatIf
  3. Install: 
    powershell -ExecutionPolicy Bypass -File .\Install-UltrawideFix.ps1 -Destination 'D:\Games\QuakeLive-Ultrawide'
    Optional: -Width 3440 -Height 1440, -SourcePath, -NoShortcut, -Force. The destination must be outside every Steam library.

The installer verifies the original file, copies the install, patches the copy's bin.pk3, deletes stale unpacked cgamex86.dll files in the copy's <steamid>\baseq3 folders, writes a managed autoexec.cfg block, and creates the shortcut “Quake Live (Ultrawide, Offline)”.

Test

  1. Steam menu → Go Offline… → Restart in Offline Mode.
  2. Launch “Quake Live (Ultrawide, Offline)”. Play → Start a Match → Offline, or /map campgrounds ffa then /addbot keel 3.
  3. Round objects should look round; you should see more at the sides; the picture fills the screen at native resolution.

Uninstall

powershell -ExecutionPolicy Bypass -File .\Uninstall-UltrawideFix.ps1 -Destination 'D:\Games\QuakeLive-Ultrawide'

Asks for confirmation, removes the copy and its shortcut. It only removes folders created by the installer and never touches the Steam install.

Limitations

  • Only the 3D view is fixed. Menus (4:3 canvas) stay stretched, and some HUD elements may too.
  • 32:9 and wider gives a very wide FOV; lower cg_fov if needed.
  • Steam updates don't touch the copy. If a game update changes cgamex86.dll, the installer refuses that version.
